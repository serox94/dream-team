# PR15/16 UI release operator

The existing migration operator and its schema28/session-reset contract remain unchanged. This separate manual operator accepts only schema30 and the exact approved PR15/16 tree ec05cea1dddbd941a0d62d8be4880a43fb41ee46. Its production action requires the existing production environment approval variable, merged approved PR heads, current main equality, no concurrent release or active Cloudflare build, and preserved bindings/configuration.

Before maintenance it exports a fresh private D1 snapshot including sequences, checks every table, stores previous Worker metadata and Time Travel bookmark, restores the snapshot into a NEW disposable D1 and verifies every table/schema/sequence/foreign key. Production R2 is read-only: media is copied to a dedicated private archive, restored into a different bucket and verified by content and metadata. The candidate is tested behind a secret request gate against the disposable clone, without AI or Tavily inference and without cron. Copied sessions are removed only from this new disposable clone.

After a final drift/queue check, maintenance blocks writes, exact approved code is deployed with existing live flags/secrets/bindings, and maintenance is restored to its original OFF state. No SQL migration or production session purge is invoked. Production smoke uses only GET business requests and its own login/logout sessions; model requests are suppressed. Original account credentials, original session rows, all business rows, saved translations and source R2 inventory are checked again. A schema30-only Worker rollback is available on failure; no D1 rollback or replacement is automatic.

Only sanitized status is uploaded as an Actions artifact. SQL, account/session rows, gateway keys and private recovery metadata remain in private R2/temp storage. Disposable Workers/D1 are deleted after use; archive buckets remain private recovery evidence. Existing PRO2 preview is never reset or rebound.
